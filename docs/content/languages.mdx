# Supported Languages

PhosAI utilizes multilingual language conditioning with one-hot prompt vector embeddings, enabling support for 40 languages and dialects.

## Language Selection

Pass the target language code in query parameters:
- REST: `POST /v1/transcribe?language=es`
- WebSocket: `wss://.../v1/realtime?language=es`
