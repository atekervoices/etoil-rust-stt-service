# Real-Time WebSocket Streaming

The PhosAI WebSocket streaming endpoint (`/v1/realtime`) enables live audio streaming directly from microphones, telephony lines, or client apps with continuous incremental token emission.

## Endpoint Details

- **Protocol**: WebSocket Secure (`wss://`)
- **Staging URL**: `wss://stt-staging.atekervoices.com/v1/realtime?language=en`
- **Audio Format**: 16,000 Hz, 16-bit Linear PCM, Mono.
- **Streaming Cadence**: Stream audio buffers in real-time as they are recorded (e.g., 20ms to 200ms buffers). The PhosAI engine automatically buffers and transcribes incoming speech in real time.

---

## Transport Modes

### 1. Raw Binary Mode (Recommended)
Send raw 16-bit PCM byte chunks directly as WebSocket **binary frames**.
- **Lowest CPU overhead**: Zero Base64 encoding.
- **Minimum latency**: Immediate streaming directly into the audio pipeline.

### 2. JSON Base64 Mode
Send audio inside standard JSON text frames:
```json
{
  "type": "audio",
  "data": "<BASE64_ENCODED_PCM16_BYTES>",
  "sample_rate": 16000
}
```

---

## Server Event Lifecycle

### 1. Connection Ready
```json
{
  "type": "ready",
  "model": "phosai-streaming-voice-v1",
  "supported_languages": ["en", "es", "fr", "de", "sw", "lg", "auto"]
}
```

### 2. Interim / Partial Updates
As speech is detected, the server emits deltas with ~38ms compute response:
```json
{
  "type": "partial",
  "text": "market",
  "accumulated_text": "How do you access market",
  "confidence": 0.95,
  "timestamp": 3.15
}
```

### 3. Final Utterance & End-of-Turn
```json
{
  "type": "final",
  "text": "How do you access market information for sweet potato",
  "confidence": 0.95,
  "timestamp": 4.14,
  "processing_time": 4.14
}
```

---

## Control Messages (Client -> Server)

| Message | Purpose |
| :--- | :--- |
| `{"type": "flush"}` | Finalizes current speech and emits final transcript. |
| `{"type": "reset", "finalize": false}` | Soft reset: returns transcript without resetting audio state. |
| `{"type": "reset", "finalize": true}` | Hard reset: clears all audio buffers and resets stream state. |
